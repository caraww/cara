# چالش هفتگی cara

**صفحه‌ها:** `challenge.html` (عمومی) و `challenge-admin.html` (مدیریت با ADMIN_TOKEN، noindex).
**بک‌اند:** `lib/challenge.mjs` (مسیرهای `/api/challenge…` و `/api/admin/challenges`)، جدول‌ها: `migrations/0005_challenges.sql`.

## راه‌اندازی (یک‌بار)
1. commit و push؛ تست‌ها توی GitHub Actions اجرا می‌شن.
2. از workflow «Apply customer accounts migration (production)» مایگریشن‌ها رو اجرا کن (`0005` رو هم می‌گیره).
3. Worker رو دیپلوی کن.

## یه چالش
1. `/challenge-admin.html` → رمز ادمین → «ساخت چالش جدید» (عنوان، موضوع، تاریخ شروع/پایان، درصد جایزه، رنگ‌های مجاز). وضعیت «فعال» طبق تاریخ‌ها عمومی می‌شه.
2. مشتری طرحش رو از استودیو می‌سازه، با تلگرام وارد می‌شه و توی `/challenge.html` ثبت می‌کنه.
3. طرح‌ها اول «در انتظار»ن؛ از «مدیریت طرح‌ها» تأیید یا رد کن. فقط تأییدشده‌ها عمومی می‌شن و رأی می‌گیرن.
4. بعد از پایان: چالش رو «ببند»، طرح برنده رو «برنده» کن، بعد «ساخت کد جایزه». کد `CARA-XXXXXXXX` و یه پیام آماده برای برنده می‌گیری (۷ روز اعتبار، فقط یک‌بار ساخته می‌شه).

## قوانین ثابت
- ورود با تلگرام لازمه؛ هر نفر یک طرح و یک رأی برای هر طرح؛ رأی به طرح خودت ممکن نیست.
- فقط «نام مستعار» عمومی نشون داده می‌شه. تماس با برنده فقط توی پنل ادمین دیده می‌شه.
- ثبت دوباره، طرح قبلی رو عوض می‌کنه، به «در انتظار» برمی‌گرده و رأی‌ها صفر می‌شن.
- صفحه‌ی مدیریت و پرداخت تگ آمار ندارن.

## تست
`npm test`؛ تست‌های چالش روی SQLite واقعی (Node 22) اجرا می‌شن و روی Node 20 خودکار skip می‌شن.
