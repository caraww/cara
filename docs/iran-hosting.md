# دسترسی سایت از ایران بدون VPN

## تشخیص

دامنه‌ی `caraw.ir` الان از دو لایه‌ای عبور می‌کند که هر دو برای بخشی از کاربران ایرانی دردسرسازند:

- DNS دامنه روی Cloudflare است و پاسخ‌های `104.21.x` و `172.67.x` می‌دهد. این محدوده‌ها روی بعضی اپراتورهای موبایل و خانگی ایران مسدود یا به‌شدت کند می‌شوند.
- فایل‌های استاتیک از GitHub Pages می‌آیند. GitHub و GitHub Pages هم برای برخی IPهای ایران در دسترس نیستند.

برای همین تغییر CSS یا JS مشکل را حل نمی‌کند؛ باید فایل‌های سایت از یک هاست ایرانی سرو شوند و دامنه دیگر مجبور نباشد از Cloudflare عبور کند.

## راه‌حل پیشنهادی: هاست ایرانی موجود

هاست `relay.caraw.ir` روی `88.135.68.30` (میزبان‌فا) است و از ایران در دسترس است. همان هاست می‌تواند سایت استاتیک را هم سرو کند.

### ۱. ساخت بسته

```bash
node tools/package-static.js
```

خروجی:

- `dist/site/` — فایل‌های آماده‌ی آپلود
- `dist/cara-static.tar.gz` — همان فایل‌ها به‌صورت فشرده

اگر Node روی سیستم خودت نداری، از GitHub Actions → **Package static site** → Run workflow استفاده کن و فایل `cara-static` را از بخش Artifacts دانلود کن.

این بسته فقط فایل‌های عمومی سایت را دارد؛ `.env`، تست‌ها، کد Worker و فایل‌های سرور داخلش نیست.

### ۲. آپلود در cPanel

1. در cPanel یک Addon Domain برای `caraw.ir` بساز (یا داکیومنت‌روت آن را به پوشه‌ی دلخواه مثل `public_html/cara` وصل کن).
2. وارد File Manager همان پوشه شو.
3. `cara-static.tar.gz` را آپلود و Extract کن.
4. مطمئن شو `.htaccess` هم در ریشه‌ی همان پوشه است.
5. از بخش SSL/TLS → AutoSSL برای `caraw.ir` گواهی بگیر.

فایل `.htaccess` این کارها را انجام می‌دهد:

- MIME درست برای AVIF، WOFF2 و Web App Manifest
- فشرده‌سازی CSS/JS/HTML
- کش طولانی برای فایل‌های نسخه‌دار و no-cache برای HTML
- پروکسی `/api/*` به `https://api.caraw.ir/api/*` تا سبد خرید، حساب کاربری و پرداخت همچنان از Worker کار کنند

اگر هاست `mod_proxy` را غیرفعال کرده باشد، سایت استاتیک باز می‌شود ولی APIها کار نمی‌کنند. در آن حالت باید یا mod_proxy را از میزبان‌فا فعال کرد یا API را جداگانه روی یک سرور ایرانی اجرا کرد.

### ۳. تغییر DNS در Cloudflare

1. Cloudflare → DNS → رکورد `A` برای `caraw.ir`.
2. مقدار را `88.135.68.30` بگذار.
3. Proxy status را **DNS only** (ابر خاکستری) کن.
4. رکورد `www` را هم به همین IP با حالت DNS only تغییر بده.
5. رکورد `api.caraw.ir` را دست نزن؛ همان باید Proxy (ابر نارنجی) بماند تا Worker کار کند.

بعد از انتشار DNS، این‌ها را چک کن:

```bash
curl -I https://caraw.ir/
curl -s https://caraw.ir/api/config
```

اولی باید HTML سایت را بدهد و دومی باید JSON تنظیمات را برگرداند.

## گزینه‌ی جایگزین: ArvanCloud

اگر نمی‌خواهی فایل‌ها را دستی آپلود کنی:

1. دامنه را به ArvanCloud منتقل کن (تغییر Nameserver).
2. یک CDN با مبدأ `caraww.github.io` و Host Header برابر `caraw.ir` بساز.
3. SSL را فعال کن.
4. برای `/api/*` یک Origin جدا به `api.caraw.ir` تعریف کن، اگر پلن ArvanCloud مسیریابی بر اساس Path دارد.

این روش به آپلود ۵۶ مگابایت فایل نیاز ندارد، ولی تنظیماتش بیشتر است و باید در پنل ArvanCloud انجام شود.

## نکته‌ی مهم

تا وقتی DNS روی Cloudflare با ابر نارنجی است، هیچ تغییر کدی نمی‌تواند مسدود بودن IPهای Cloudflare روی اپراتور کاربر را دور بزند. تغییر اصلی باید در DNS و محل سرو فایل‌ها انجام شود.
